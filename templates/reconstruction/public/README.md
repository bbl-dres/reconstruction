# Published files

Everything in `public/` is committed and published on GitHub Pages: `building.json` (viewer and pipeline settings), `about.html` (help text), `models/` (catalog and versioned GLB, BIM and IFCZIP assets written by `tools/model-pipeline`), `profiles/` (export profiles), `previews/` and `docs/`. Never place evidence, plans, photos or tour downloads here; they belong in `../work/`.
