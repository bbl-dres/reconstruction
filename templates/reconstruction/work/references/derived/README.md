# references/derived

Faithful page previews, drawing crops/tiles, rectifications and text extracts keyed to a registered original source ID; never replace originals. Preserve extraction parameters and source links.

Photographs extracted from documents go under `../photos/` with their parent links retained. Traces, annotations, interpreted geometry, model renders and comparison sheets belong in `research/` or `build/review/`.

For heavy PDFs, provide a colour PNG overview at roughly 2048 pixels on the long edge and link it from a collection/source README. Reuse existing raster access copies. Keep the PDF unchanged. Small dimensions need a bounded crop or overlapping tiles around 1200–1800 pixels, with source page and crop coordinates recorded; do not assume every label is readable in a whole-page overview. Existing larger previews cited by controls remain valid detail assets. Avoid redundant conversions with the same purpose.
