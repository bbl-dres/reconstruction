# Build

The living authoring folder ([conventions](../../../../docs/conventions.md#work-folder)).

| Path | Content |
|---|---|
| `scripts/` | Every script this building needs, flat, with the prefixes s / c / b / v / r |
| `model/` | Working `.blend`, generated specs, textures |
| `review/` | Latest check results and review images; overwritten by every run |
| `tmp/` | Scratch (import profiles, IFC scratch, logs); not tracked |
