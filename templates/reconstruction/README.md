# Reconstruction template

Starter for a new Blender-authored building. Copy this folder to `reconstructions/<id>/` and follow [Adding a building](../../docs/adding-a-building.md).

| Path | Content |
|---|---|
| `index.html` | Thin entry page for the shared viewer, using the default policy |
| `public/` | `building.json`, `about.html`, export profiles – committed and published |
| `work/` | Authoring workspace skeleton: evidence library, research, stages, versions, record templates, `.gitignore` and `.gitattributes` for the private work repository |

The skeleton contains no Bundeshaus model, evidence, IDs, coordinates or source rights. Do not carry those over.
