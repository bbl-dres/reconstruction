# Bundeshaus

The Swiss Parliament Building in Bern, built 1894–1902.

> [!WARNING]
> **Experiment – for viewing only.** Built from publicly available data. Not survey-grade and not accurate: do not use it for measurements, planning or any other purpose.

- **Viewer:** [bbl-dres.github.io/reconstruction/reconstructions/bundeshaus](https://bbl-dres.github.io/reconstruction/reconstructions/bundeshaus/)
- **Run locally:** `python tools/serve.py --building bundeshaus`
- **Made with:** Blender

`public/` is published ([files](public/README.md)); `work/` is the private workspace, gitignored and never published.
