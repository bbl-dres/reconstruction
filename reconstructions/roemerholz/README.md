# Sammlung Oskar Reinhart «Am Römerholz»

Oskar Reinhart's villa and picture gallery in Winterthur, built 1915–1918; a museum since 1970.

> [!WARNING]
> **Experiment – for viewing only.** Built from publicly available data. Not survey-grade and not accurate: do not use it for measurements, planning or any other purpose.

- **Viewer:** [bbl-dres.github.io/reconstruction/reconstructions/roemerholz](https://bbl-dres.github.io/reconstruction/reconstructions/roemerholz/)
- **Run locally:** `python tools/serve.py --building roemerholz`
- **Made with:** Revit

`public/` is published ([files](public/README.md)); `work/` is the private workspace, gitignored and never published.
