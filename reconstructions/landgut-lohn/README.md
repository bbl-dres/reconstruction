# Landgut Lohn

The Federal Council's country residence in Kehrsatz, built 1782/83.

> [!WARNING]
> **Experiment – for viewing only.** Built from publicly available data. Not survey-grade and not accurate: do not use it for measurements, planning or any other purpose.

- **Viewer:** [bbl-dres.github.io/reconstruction/reconstructions/landgut-lohn](https://bbl-dres.github.io/reconstruction/reconstructions/landgut-lohn/)
- **Run locally:** `python tools/serve.py --building landgut-lohn`
- **Made with:** Blender

`public/` is published ([files](public/README.md)); `work/` is the private workspace, gitignored and never published.
