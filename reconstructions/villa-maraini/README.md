# Villa Maraini

Seat of the Swiss Institute in Rome, built 1903–1905.

> [!WARNING]
> **Experiment – for viewing only.** Built from publicly available data. Not survey-grade and not accurate: do not use it for measurements, planning or any other purpose.

- **Viewer:** [bbl-dres.github.io/reconstruction/reconstructions/villa-maraini](https://bbl-dres.github.io/reconstruction/reconstructions/villa-maraini/)
- **Run locally:** `python tools/serve.py --building villa-maraini`
- **Made with:** Revit

`public/` is published ([files](public/README.md)); `work/` is the private workspace, gitignored and never published.
